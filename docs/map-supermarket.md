# Карта: супермаркет (тестовая, серая)

**Статус (решено 2026-10-07):** супермаркет больше не основная карта. Основная карта демо — ресторан (`map-restaurant.md`), туда перенесены порядок работы, уровни качества и правила оформления. Супермаркет остаётся серой картой для проверки механик и ботов, в арт не доводится.

- Сцена `Assets/Scenes/Supermarket.unity`, собирается Editor-скриптом `SupermarketMapBuilder` (меню PropHunt/Build Supermarket Map) из примитивов.
- Размер 20×14 м: зал с 3 рядами стеллажей, касса у входа, подсобка; вход закрыт дверями `Entrance_Doors`.
- На ней работают автотесты ботов (`Assets/Editor/BotPlayTest.cs`) и навмеш для пряток на полках (`ShelfNavBuilder`).
- Привязки кода к этой карте (имена объектов, координаты в тестах) нужно убрать, чтобы те же боты и тесты работали на ресторане — см. `STATUS.md`, «Следующие шаги».
