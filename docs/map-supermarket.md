# Карта: супермаркет (MVP)

- Одна карта, вручную (не процедурная). Реиграбельность даёт рандомизация предметов (`systems/spawn.md`).
- Компактная: вход, 3-4 ряда стеллажей, касса, небольшая подсобка. Холодильная витрина, стенд с овощами.
- Не просто стеллажи, а **тематические зоны спавна** с привязанной темой и сеткой точек.
- Предметов больше, чем игроков.

## Порядок работы (решено: обновлено)
1. **MVP:** серая карта из примитивов (ProBuilder), простые материалы (цвет не важен на этом этапе), без запечённого света. Цель — проверить механику, не красоту. **Размер: 20×14 м (~280 м², решено)** — баланс между играбельностью и компактностью: достаточно места для 3-4 рядов стеллажей + кассы + подсобки, но не настолько большой, чтобы развести игроков и обесценить маячок (радиус слышимости 14-15 м, `systems/beacon.md`) на карте с 4-10 игроками. Небольшой продуктовый, не гипермаркет. См. `demo-scope.md`, MVP идёт первым.
2. **После подтверждения, что играть весело:** тестовая комната (`style-test-room.md`) — настройка шейдера, света, bloom на нескольких простых объектах, сравнение с референсом.
3. **Крупная мебель через Tripo (решено — расширено, не только предметы пряток):** стеллажи, касса, холодильная витрина, стенд с овощами генерируются в Tripo по одному объекту на промпт (`art-pipeline.md`, правило «один промпт = один объект»). Даёт настоящую детализированную форму со скруглениями, а не примитив.
4. **Только капитальная оболочка** (стены, пол, потолок, проёмы, вход, подсобка) — по-прежнему из примитивов кодом с фасками и молдингами (`## Как скрыть...` ниже): Tripo плохо держит большие плоские интерьерные формы, для отдельных предметов он куда лучше.
5. **Мелкие предметы для маскировки:** CC0-наборы + точечно Tripo, каждый предмет отдельным промптом.
6. Сетки точек и пулы через Editor-скрипт.
7. Свет запекать (baked), не realtime; цветные источники по зонам, emissive на вывесках и витринах.

**Подключение Tripo к Claude Code через MCP (решено: пока нет.)** Официальный Tripo MCP существует, но альфа-версия, требует параллельно запущенный Blender MCP, и расходует кредиты Tripo без прямого контроля за каждой генерацией. Пока работаем вручную: промпт из Claude → сайт Tripo → скачали → импортировали в Blender/Unity сами. Вернуться к вопросу позже, если ручной процесс станет узким местом.

Стеллаж делать префабом с точками спавна внутри.

## Уровни качества карты (предложено)
1. **Демо:** примитивы и ProBuilder с фасками, палитра, цветной запечённый свет, bloom, графичные узоры на полу и стенах (плитка, полосы, ромбы). Узоры генерировать скриптом (процедурно или Python), это не ИИ-контент.
2. **После подтверждения механики:** предметы из CC0-наборов и Tripo, модули со скруглёнными фасками через Blender (Bevel, Subdivision).
3. **Перед релизом:** художник на ключевые элементы (вывеска, узор пола, главные предметы, декор).
Переход на следующий уровень решается по результатам тестовой комнаты (`style-test-room.md`).

## Как скрыть, что база собрана из примитивов (предложено)
Задача: архитектура (стены, пол, потолок, стеллажи, касса) не должна выглядеть как набор коробок. Предметы для маскировки идут из Tripo, база строится кодом.
1. **Скругление всех рёбер.** Единая фаска ~2-4 см на всех деталях (ProBuilder Bevel, свой генератор «rounded box» в Editor-скрипте или Bevel в Blender). Острые углы 90° главный признак примитива.
2. **Молдинги и обвязка:** плинтусы, карнизы, дверные рамы, панели на стенах, обшивка кассы, кромки полок, колонны или пилястры.
3. **Разные формы:** не только прямоугольники, добавить скруглённую кассу, арки, круглые колонны, наклонные вывески, потолочные балки или панели.
4. **Вариативность:** стеллажи разной высоты и цвета, лёгкая асимметрия, нерегулярные промежутки, разное количество полок. Повторяющиеся идентичные модули выдают сборку.
5. **Не плоские цвета:** лёгкий градиент по высоте, вертексные цвета, узоры, декали (знаки, плакаты, разметка на полу, ценники).
6. **Свет добавляет глубину:** запечённый AO и отражённый свет, цветные источники, emissive-полосы и вывески.
7. **Единый язык с Tripo-предметами:** одинаковая палитра, тот же шейдер и сопоставимая «пухлость» скруглений, иначе предметы будут смотреться чужими на базе.
8. **Мелкая детализация:** несколько растений, корзины у входа, знаки проходов (плоские квады с текстурой). Только статичный декор, не вселяемый и не сбивающий игру на несоответствиях.
