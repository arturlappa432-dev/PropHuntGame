# Открытые вопросы

## Требуют решения
1. Сроки на реализацию миграции хоста (после 15 ноября, по остатку времени до Next Fest) — решить позже.
2. Остальная схема управления: движение, стрельба, E, таран/пинок (`systems/movement-and-camera.md`).
2а. Конкретные клипы базовой локомоции охотника (бег/прицеливание/стрельба/пинок) из Quaternius Universal Animation Library — какие именно взять, требуется подбор (`art-and-audio.md`).
3. Финальные звуки прыжка/приземления (решим вместе со звуками ускорения).
4. Пересчёт сроков после определения реального темпа разработки по MVP — сделает Claude по факту, не требует ответа сейчас.
5. Стиль интерфейса (UI): подтверждён тот же пастельный стиль, что у мира (`art-and-audio.md`); детали (иконки, шрифт) не определены.
6. Подтвердить стиль по результату тестовой комнаты (`style-test-room.md`): палитра, шейдер, свет, bloom, узоры.
7. Калибровка порога яркости теней — нельзя оценить без визуальной пробы, ждёт тестовой комнаты.
8. Калибровка радиуса маячка и окклюзии через стены (`systems/beacon.md`) — числа стартовые, подстроить на плейтесте.
9. Калибровка чисел ускорения (×1,5 / 3 сек / 15 сек) — устраивают как старт, возможна донастройка на плейтесте.
10. Известная особенность формулы HP (мелкий → крупный при низком % даёт рост абсолютного HP) — не эксплойт для бесконечного абуза, но следить на плейтесте; рычаг на случай проблемы: поднять шаг 0,10 → 0,15 (`balance.md`).

## Решено (для справки)
- Near-miss свист остаётся; выход хоста в лобби завершает игру, в матче — миграция через Fusion Host Migration API кроме случая «хост был единственным охотником» (тогда завершение), не входит в MVP/демо (`networking.md`, `decisions.md`).
- Прыжок: Space, без анимации/риггинга у обеих ролей; squash-and-stretch + толчок камеры; без звука отрыва, со звуком приземления; пыль при приземлении не добавляем (`systems/movement-and-camera.md`, `decisions.md`).
- Unity 6.3 LTS, Fusion Host Mode, MCP for Unity, git — см. `CLAUDE.md`, `networking.md`.
- Критерии «продолжать / менять / бросать»: первая играбельная MVP-версия с ботами (`demo-scope.md`, `roadmap.md`).
- Ускорение: клавиша Z, без звука, ×1,5 / 3 сек / восстановление 15 сек, активация одним нажатием без удержания (`systems/boost.md`).
- Колесо охотника при нескольких охотниках: по одному вращению на каждого, без повторного выбора (`systems/lobby.md`).
- Значения лобби по умолчанию подтверждены (`GDD.md`).
- Кулдаун ручного маячка: 1 сек (`systems/beacon.md`).
- Радиус маячка: 14 м по прямой + приглушение через стены (`systems/beacon.md`).
- Третье лицо у охотника по умолчанию включено (`GDD.md`).
- Дистанция наведения для превращения: ~4 м (`systems/possession.md`).
- Учёт ассетов и раскрытие ИИ в Steam: ведёт лично владелец проекта (`assets-licenses.md`).
- Дифференциатор: таран и пинок как фирменная фишка (`systems/ram-kick.md`) + живые 2D-лица на предметах как вторая фирменная фишка (`systems/faces.md`, статус повышен с запасного варианта — история в `parked.md`).
- Ragdoll охотника: упрощённый риг 6-8 тел, финально, не временная оптимизация (`performance.md`, `decisions.md`).
- Пинок: самовыравнивание после оглушения (`systems/ram-kick.md`).
- Tripo используется и для крупной мебели, не только предметов пряток; подключение через MCP пока не делаем (`map-supermarket.md`, `art-pipeline.md`).
