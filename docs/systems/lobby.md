# Лобби и лобби-комната

## Создание
- В меню игрок вводит только данные лобби (название, публичное или приватное).
- Публичные лобби отображаются в списке; приватные по приглашению или коду.

## Лобби-комната
- После создания создатель (хост) переносится в отдельную 3D-комнату. Остальные игроки входят туда же.
- На стене меню с настройками правил (см. таблицу в `../GDD.md`). Видят все, **меняет только создатель**.
- Создатель получает **лазерную указку** для выбора настроек. Указку нельзя выбросить; она исчезает при старте игры.
- Реализация: UI в мировом пространстве, указка как луч из камеры, права проверяются на хосте (не только в интерфейсе).

## START и колесо охотника
- Рядом с меню кнопка START. После нажатия крутится колесо выбора охотника.
- **Результат выбирается на хосте заранее**, колесо только анимируется до этого результата (одинаково у всех игроков).
- **Решено:** если охотников больше одного, колесо крутится по одному разу на каждого охотника подряд. Игрок, уже выбранный предыдущим вращением, исключается из пула кандидатов следующих вращений (не может быть выбран повторно).

## Ограничения настроек
- Число охотников не больше половины игроков (предложено). Недоступные кнопки неактивны.
- Поле «своя длительность»: целое от 1 до 30, при включённой галочке перекрывает кнопки.
