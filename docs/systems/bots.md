# Боты (для демо)

**Цель:** не оставлять лобби пустыми во время Next Fest. Первый этап: только боты-прячущиеся при охотнике-человеке.

## Бот-прячущийся (предложено)
**Оптимизация (решено, не влияет на поведение):** пересчёт решений бота реже, когда он далеко от охотника (~раз в 0,3 сек), чаще при приближении угрозы. Частота тика не связана с тем, насколько бот интересен как противник или союзник — за это отвечает логика состояний и баланс ниже.
- Выбор предмета с оценкой «естественности» места (рядом с однотипными, не посреди прохода).
- Состояния: замереть (основное состояние — сохранять маскировку), изредка переместиться, убегать ТОЛЬКО при реальном обнаружении (попадание по боту или near-miss выстрел рядом, hunter-combat.md) — НЕ при простом приближении охотника. Простое приближение не должно триггерить побег, иначе бот сам выдаёт себя раньше времени, разрушая саму идею маскировки среди предметов. Таран и повторное превращение по ситуации (после обнаружения).
- Навигация через NavMesh, использует тот же ввод и правила, что и игрок.
- Сложность настраивается параметрами (частота движения, дальность замечания охотника), а не читами.
- Разные «личности» (осторожный, наглый) для вариативности.

### Реализация (2026-10-03, `HiderBot`, `BotSpawner`)
- Состояния: Seek (выбор и поход к предмету) -> Possessing -> **Freeze** (основное) -> изредка Relocate -> Settle; при обнаружении Reacting -> Flee (или Ram) -> Settle -> Freeze. Обнаружение = только события `HiderPlayer.Detected`: попадание, near-miss (свист), пинок. Приближение/взгляд охотника не триггерят ничего.
- Ввод: `BotInput` (то же, что клавиши: движение, прыжок, Z, E + yaw/pitch), правила те же (скорость, кулдаун смены 12 с, дистанция вселения, шкала Z, таран). Для E бот целится лучом из глаз; подсветка цели у ботов не рисуется (игроку не видно, куда он метит).
- Знание бота: свободные предметы (то же, что даёт подсветка игроку), позиции предметов, охотник — только по прямой видимости (луч). Какой «прячущийся» настоящий игрок, бот не знает. Расстояние до охотника без видимости используется только для частоты тиков.
- Личности (`BotPersonality`): осторожный (реакция 0,25 с, бег 7 с, таран 15%, перемещение раз в ~45 с, замечает охотника до 16 м) и наглый (0,6 с, 3,5 с, таран 70%, ~20 с, 8 м). Значения предложены мной, см. `open-questions.md`.
- Ограничение: бот на полке не перемещается по своей воле (по NavMesh ходит только с пола); при обнаружении он спрыгивает к ближайшей точке навмеша и бежит.
- Пойманный бот выбывает, охотником не возрождается (бот-охотник отложен).

## Бот-охотник
Отложен. Должен честно имитировать восприятие (проверка зон, ограниченные признаки подозрения, задержки, ошибки), без знания настоящих предметов.

## Побочная польза
Ботов можно гонять сотни раундов без людей для проверки баланса (`../balance.md`).
