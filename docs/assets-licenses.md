# Учёт ассетов и лицензий

**Ведёт лично владелец проекта** (решено), не агент. Правило: любой ассет из внешнего источника или сгенерированный ИИ записывать сюда. Данные нужны для анкеты Steam (раскрытие ИИ) и для проверки лицензий.

| Ассет | Источник | Лицензия | Сделан ИИ (да/нет) | Коммерческое использование проверено | Заметки |
|---|---|---|---|---|---|
| (пример) Kenney Food Kit | kenney.nl | CC0 | нет | да | |
| (пример) Клоунский звук маячка | (указать) | (указать) | (указать) | (проверить) | |

## Напоминания
- Tripo free tier: только для проверки стиля (CC BY 4.0, без коммерческих прав). Финальные ассеты генерировать на платном тарифе.
- Проверять права на каждый набор отдельно, читать лицензию на странице.
- Нельзя использовать модель охотника или белого человечка из Meccha Chameleon и любые файлы с её названием.
